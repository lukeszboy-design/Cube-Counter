# Cube Counter Calculator

A kid-friendly calculator where every number is a friendly robot carrying its counting cubes.

- Press a number and a robot appears holding that many cubes, and a cheerful British voice says the number.
- Press **=** for a trumpet fanfare, confetti, and the answer shown as cubes, tens bars and hundreds squares, read out loud.

## Play it
**In your browser:** https://lukeszboy-design.github.io/Cube-Counter/

## Download the app
- **Windows:** [CubeCounterCalculator.exe](https://github.com/lukeszboy-design/Cube-Counter/releases/latest/download/CubeCounterCalculator.exe)
- **Mac with Apple chip (M1 or newer):** [CubeCounterCalculator-mac-AppleSilicon.zip](https://github.com/lukeszboy-design/Cube-Counter/releases/latest/download/CubeCounterCalculator-mac-AppleSilicon.zip)
- **Older Intel Mac:** [CubeCounterCalculator-mac-Intel.zip](https://github.com/lukeszboy-design/Cube-Counter/releases/latest/download/CubeCounterCalculator-mac-Intel.zip)

The apps load the newest version of the website each time they open, and use a built-in copy when there's no internet.

**Opening it the first time**
- Windows: if you see "Windows protected your PC", click **More info**, then **Run anyway**.
- Mac: unzip, drag the app into Applications, then right-click it and choose **Open**, then **Open** again.

Voice recorded with [Kokoro](https://github.com/hexgrad/kokoro), an open-source text-to-speech model.
