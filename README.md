# Cube Counter Calculator

A kid-friendly calculator where every number is a friendly robot carrying its counting cubes.

- Press a number and a robot appears holding that many cubes (and a happy voice says the number).
- Press **=** for a trumpet fanfare, confetti, and the answer shown as cubes, tens rods and hundreds flats.

**Play it here:** https://lukeszboy-design.github.io/Cube-Counter/

To update the site, replace `index.html` in this repository. GitHub Pages publishes the change within a minute or two, and the Mac and Windows apps pick it up the next time they open.
